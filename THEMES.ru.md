# Темы оформления — 0.8.0-2

Откройте вкладку **«Темы»** с иконкой кисти в левой панели. Нажмите карточку, чтобы применить палитру ко всему приложению. Выбор сохраняется в настройках лаунчера и восстанавливается при следующем запуске.

Каждая тема имеет свою палитру, форму частиц и характер движения. Светлые темы — «Хрустальный иней» и «Пески времени». Базовые тёмная, светлая и OLED-темы остаются доступны без декоративных эффектов.

## Настройка эффектов

- Переключатель **«Летающие частицы»** полностью отключает фоновые эффекты.
- Режимы **«Лёгкие» / «Баланс» / «Насыщенные»** меняют количество частиц; выбор сохраняется локально.
- Один общий Canvas работает с ограничением до 30 кадров/с и плотностью пикселей до 1,5. Миниатюры статичны и не создают отдельные циклы анимации.
- При потере фокуса и скрытии окна анимация приостанавливается. Системное предпочтение уменьшения движения также отключает движение.
- При ошибке сохранения темы прежний выбор восстанавливается и показывается сообщение.

## Проверка изменений

```sh
pnpm --filter @modrinth/app-frontend test
pnpm --filter @modrinth/app-frontend build
cargo test -p theseus --lib --locked
```

Dev-страница `apps/app-frontend/tests/theme-preview.html` запускает настоящий интерфейс приложения с mock IPC Tauri для проверки переключения тем в браузере. Она не входит в production entry point и не заменяет проверку установленного приложения под Windows.

Проверены 13 палитр и моделей частиц, контраст основного текста, сохранение и откат настроек, отключение эффектов, уменьшение движения и остановка анимации при потере фокуса. Эти проверки не подтверждают работу каждой версии Minecraft и каждого модпака: игровое тестирование нужно выполнять отдельно.
