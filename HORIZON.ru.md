# Minecraft Rust

Интеграция Horizon в U3drinth. Windows x64.

## Использование

1. Открой вкладку Minecraft Rust и нажми «Установить Horizon».
2. Добавь аккаунт Microsoft. Вход проходит в браузере по коду устройства, пароль не вводится в U3drinth.
3. Выбери папку с законно установленной Minecraft Java 26.3 или нажми «Скачать и подготовить». Скачивание Minecraft выполняет Horizon после проверки лицензии.
4. Выбери или создай профиль. Выбери «Офлайн» с ником или «С лицензией» с аккаунтом, нажми «Играть».

Офлайн-ник - не обход лицензии. Выпущенный CLI Horizon требует добавленный аккаунт, владеющий Minecraft, и для этого режима. Проверки не отключаются. Аккаунты обычного U3drinth автоматически в Horizon не переносятся.

Horizon не запускает Java-моды Fabric, Forge и NeoForge. Старые Java-сборки не преобразуются автоматически.

## Реализация

- Вкладка управляет официальным `horizon-launcher` через CLI. Его окно не открывается. Движок запускается отдельным нативным процессом.
- Компонент зафиксирован на официальном выпуске `launcher@0.2.28`. SHA-256 архива и exe зафиксированы в коде; exe проверяется перед каждым запуском. Если он изменён, выполнение блокируется.
- «Обновить игру» получает актуальную сборку игры через CLI. Сам компонент интеграции обновляется вместе с U3drinth, а не заменяет себя неизвестной версией.
- Выбор файлов ограничен подготовкой из папки Minecraft. Команды и аргументы фиксированы, shell не используется, произвольные аргументы игры не передаются.
- Данные находятся в `<settings_dir>/minecraft-rust`: `runtime`, `launcher`, `game`. Обычные профили U3drinth и отдельная установка Horizon не изменяются.
- Учётными данными управляет Horizon, секреты хранит в системном хранилище. U3drinth получает имена, UUID и кратковременный код входа, но не токены или пароль.
- Работа продолжается при переходе на другую вкладку. Повторные операции блокируются до завершения. Вход Microsoft можно отменить. Игра завершается через своё окно.
- Прогресс загрузки компонента показывается в процентах. CLI установки игры и подготовки не выдаёт проценты в pipe: показываются этап и журнал, без выдуманного процента.
- Проверка готовности основана на ресурсном манифесте выбранной версии. Валидация игровых файлов и совместимость остаются ответственностью Horizon.
- Полный запуск игры, подготовка из лицензионных файлов и вход реального пользователя требуют проверки на пользовательском Windows. Автотесты не подменяют эту проверку.
