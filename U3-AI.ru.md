# U3drinth (custom modrinth) v1.0 — U3 AI

## Установка из приложения

Открой U3 AI и нажми «Установить ИИ». U3drinth скачает официальный OllamaSetup.exe, проверит доверенную подпись издателя Ollama Inc., установит Ollama в учётную запись Windows и скачает qwen2.5:1.5b через локальный API. Ручные команды не нужны.

- Нужен интернет и около 8 ГБ свободного места с учётом временного установщика. На момент обновления установщик около 1.7 ГБ, модель около 1 ГБ; размеры будущих выпусков Ollama могут отличаться.
- Загрузка начинается только после нажатия. Прогресс относится к текущему файлу/слою модели, а не ко всей установке.
- Загрузку можно остановить и запустить повторно. Во время работы самого установщика отмена недоступна.
- Ollama устанавливается отдельно и может работать в фоне. Удаляется через настройки Windows; уже скачанные модели могут остаться на диске.
- Для установки используется только официальный HTTPS-адрес, разрешённые редиректы GitHub и проверка Authenticode. При неверной подписи ничего не запускается.
- Модель работает на CPU, 4 потока, контекст 4096, выгрузка после ответа. Во время игры можно вообще не обращаться к модели.
- Если Ollama уже запущен, загружается только недостающая модель.

Автоматическая установка доступна в Windows x64. Это отдельный, явно запущенный пользователем установщик; модель не имеет доступа к командам установки или оболочке.


## Первый запуск локального ИИ

1. Установите Ollama с https://ollama.com/download/windows и запустите его.
2. В терминале выполните `ollama pull qwen2.5:1.5b`. Модель скачивается отдельно; установщик U3drinth не содержит её и ничего не скачивает скрытно.
3. Откройте U3 AI в боковой панели и нажмите «Проверить подключение».

Используется только локальный адрес `127.0.0.1:11434`, без облачного API. Фиксированная локальная модель Qwen2.5 1.5B работает в режиме CPU: 4 потока, контекст 4096, до 768 токенов ответа. `keep_alive: 0` выгружает модель после ответа; `num_gpu: 0` оставляет видеопамять игре. Для ПК с 16 ГБ RAM и GTX 1650 это консервативная настройка, а не обещание конкретной скорости. Во время генерации CPU и RAM всё равно используются. Производительность на реальном ПК нужно проверить отдельно.

Диалог хранится только в памяти приложения. Логи не отправляются в облако. Каталог и загрузки модов обращаются к настоящему API Modrinth и требуют интернет. Без модели работают ручной конструктор, файловые инструменты и быстрая диагностика по правилам — она явно подписана, это не имитация ИИ.

## Сборки и коллекции

- Попросите модель предложить проекты либо найдите моды, ресурс-паки и шейдеры вручную.
- Выберите Minecraft и загрузчик. Проверка плана подбирает версии, учитывает обязательные зависимости и заявленные несовместимости; неподходящий план блокируется.
- Перед скачиванием показывается список файлов. Создание требует отдельного подтверждения и создаёт новый профиль, не меняя прежние.
- При сетевой ошибке или отзыве разрешения установка прекращается. Неполный профиль сохраняется с явным сообщением об ошибке, а не выдаётся за готовый.
- Проекты можно сохранить в `u3-collections/*.json` внутри выбранного профиля. Откройте файл в помощнике и загрузите его в конструктор для повторной проверки под другую версию.
- План ограничен 24 выбранными проектами и 64 файлами вместе с зависимостями. Проверка метаданных не гарантирует отсутствие игровых конфликтов. ИИ может ошибаться и предлагать несуществующие проекты.

## Файловый доступ

Доступ включён по умолчанию, как запрошено, и отключается переключателем в U3 AI. Разрешение сохраняется в `u3-ai.json` в каталоге настроек. Неверный или недоступный файл разрешений блокирует файловые операции. При отключении удаляются подготовленные планы и очищается контекст диалога в интерфейсе.

Инструменты ограничены профилями, зарегистрированными в лаунчере, и папками `mods`, `resourcepacks`, `shaderpacks`, `config`, `logs`, `crash-reports`, `u3-collections`. Нет произвольных путей, командной строки, запуска программ или удаления файлов. Пути с обходом каталога, специальные Windows-пути и ссылки блокируются. Это ограничения инструментов помощника, а не системная песочница для всего старого лаунчера.

- Текст логов читается ограниченным фрагментом; распространённые токены и имена Windows-пользователей маскируются. Перед прикреплением всё равно просмотрите текст: маскирование не гарантирует удаления всех личных данных.
- Конфиги редактируются только как существующие текстовые файлы до 128 KB. Перед сохранением создаётся копия в `.u3-backups`. Конфиги с распознанными секретами не перезаписываются через помощника. Для восстановления закройте игру и вручную верните резервную копию на исходное место.
- Моды и пакеты можно включить/отключить переименованием с `.disabled`, без удаления. Требуется подтверждение.
- Изменения конфигов и переключение модов блокируются, пока соответствующий профиль запущен.
- После завершения игры локальная проверка последних логов может показать предупреждение на значке U3 AI. Совпадение с правилом не доказывает причину вылета. Отправка лога модели происходит только при явном прикреплении к сообщению.

## Интерфейс v1.0

Переключатель RU/EN находится в верхней панели и настройках. Переведены основные экраны лаунчера, темы и U3 AI; названия проектов, их описания, диагностические строки внешних сервисов и часть старых вспомогательных диалогов могут оставаться на языке источника.

Удалены рекламные блоки Promotion и кнопки Get support. Добавлена собственная багровая иконка U3, заменены нативные размеры значков и заставка. Значки получают короткую упругую анимацию, вкладки — плавный переход с кратким размытием. При системном уменьшении анимации эти эффекты отключаются.

Видимая версия: `U3drinth (custom modrinth) v1.0`, пакет: `1.0.0`, издатель в метаданных: `U3`. Это НЕ цифровая подпись: SmartScreen может по-прежнему показывать неизвестного издателя или предупреждение. Для доверенного издателя нужен настоящий сертификат подписи кода.

## Проверка

```sh
pnpm --filter @modrinth/app-frontend test
pnpm --filter @modrinth/app-frontend build
cargo test -p theseus --lib --locked
```

Браузерный dev-harness проверяет интерфейс на mock IPC: подключение/отсутствие модели, подтверждения, выключение доступа, работу двух языков, диагностику, адаптивную вёрстку. Mock-ответ модели не является тестом реального Ollama. Реальные ответы модели, FPS Minecraft и обновление установленного Windows-приложения требуют отдельной проверки на пользовательском ПК.
