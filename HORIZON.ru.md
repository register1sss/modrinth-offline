# Minecraft Rust

Интеграция Horizon в U3drinth. Windows x64.

## Запуск одной кнопкой

Открой Minecraft Rust и нажми «Играть». Ник уже заполнен, отдельная установка Horizon, выбор папок и ручная подготовка не нужны.

При первом запуске U3drinth автоматически:
1. Загружает проверенный официальный компонент Horizon, если он отсутствует или повреждён.
2. Устанавливает движок. Старые установки без контрольной суммы также переустанавливаются автоматически.
3. Ищет Minecraft в текущей папке данных U3drinth (включая пользовательский путь из настроек), затем в стандартных папках поддерживаемых Horizon лаунчеров: официального Minecraft, Prism, MultiMC, Modrinth и других. Horizon сверяет файлы с контрольными суммами нужной версии.
4. Подготавливает ресурсы и запускает выбранный профиль, по умолчанию Horizon.

При повторном запуске проверенный движок и подготовленные ресурсы используются повторно. Ненужной загрузки и подготовки нет. Первичная установка и подготовка могут требовать интернет, Java подбирает Horizon.

Если нужных файлов Minecraft нет ни в одной найденной папке, сам автопоиск не заменяет их загрузку. Установи и запусти Minecraft Java 26.3 один раз в обычном лаунчере, затем снова нажми «Играть». Выбирать папку не требуется. Также можно загрузить Minecraft через аккаунт с лицензией в «Настройках запуска». Если автоматическая подготовка не удалась, показываются понятное сообщение и журнал, игра не запускается с неполными ресурсами.

Офлайн-режим включён по умолчанию, аккаунт Microsoft и проверка владения для самого запуска не нужны. Подходят одиночная игра, LAN и серверы в offline-mode. Это не даёт доступ к серверам с проверкой аккаунта.

Дополнительные профили, режим с лицензией, вход Microsoft, загрузка Minecraft и переустановка Horizon находятся в свёрнутых «Настройках запуска». Вход и загрузка Minecraft используют официальный механизм Horizon и его проверку владения. Пароль не вводится в U3drinth. Аккаунты обычного U3drinth автоматически не переносятся.

Используй законно полученные файлы Minecraft. Они не включены в установщик U3drinth. Horizon не запускает Java-моды Fabric, Forge и NeoForge. Старые Java-сборки не преобразуются автоматически.

## Реализация

- Официальный менеджер `horizon-launcher` работает через CLI без отдельного окна. Его выпуск зафиксирован на `launcher@0.2.28`, SHA-256 архива и exe зафиксированы в коде. Проверка выполняется перед каждым запуском менеджера.
- В офлайн-режиме U3drinth запускает подготовленный `horizon-client.exe` напрямую с фиксированными аргументами `--resources` и `--name`. Команды `account offline` и `play` менеджера, требующие аккаунт, не используются. Файл сессии не передаётся, переменная HORIZON_SESSION_FILE удаляется из среды дочернего процесса.
- После успешной установки игры менеджером из проверенного официального архива сохраняется SHA-256 движка. Прямой запуск сверяет эту сумму. Старые установки без контрольной суммы и изменённый движок автоматически заменяются официальной проверенной сборкой до запуска.
- Движок, версия, ресурсы и папка профиля проверяются по фиксированным путям и canonical path. Переходы наружу через пути и симлинки блокируются. Офлайн поддерживает локальные профили Horizon (default/own), не Java-профили или произвольные импортированные команды.
- Нативный процесс работает в папке выбранного профиля. Прочие аргументы, shell, pre/post hooks, wrapper-команды и сторонние исполняемые файлы не принимаются из UI.
- Данные находятся в `<settings_dir>/minecraft-rust`: `runtime`, `launcher`, `game`. Обычные профили U3drinth и отдельная установка Horizon не изменяются.
- Работа продолжается при переходе на другую вкладку. Повторные операции блокируются до завершения. Вход Microsoft можно отменить. Игра завершается через своё окно.
- Прогресс загрузки компонента показывается в процентах. Для этапов, где CLI не выдаёт проценты в pipe, показываются этап и журнал.
- Готовность ресурсов проверяется по манифесту выбранной версии. Полная подготовка Minecraft и запуск мира с графикой требуют проверки на пользовательском Windows. Запуск движка с `--help` не подменяет игровую проверку.
