# U3drinth

Independent Minecraft launcher based on Modrinth App, with offline accounts, updated version compatibility, 13 custom themes and unique particle effects.

Windows installer builds are available in this fork's GitHub Actions artifacts. This is not an official Modrinth release.

See [U3 AI setup and v1.0 notes](U3-AI.ru.md), [theme controls](THEMES.ru.md), [branding and upgrade notes](BRANDING.ru.md), and [compatibility changes](COMPATIBILITY-UPDATE.ru.md).

## What does this fork do?
This fork adds option to use offline accounts and launching game without requiring to log into Microsoft account
