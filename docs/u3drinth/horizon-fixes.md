# U3 Fixes 0.1.0 - первая отдельная правка движка

## Что меняется

Исправлены два клиентских перехода состояния трезубца в Horizon 3132240:

- Локальное столкновение обнуляет скорость и устанавливает `in_ground`. В исходном `Game::remote_motion` последующий пакет сервера заменяет скорость, но не снимает этот флаг. `ThrownTrident::remote_tick` после этого возвращается, не сдвигая трезубец. HEAD-инъекция снимает флаг для конечной ненулевой скорости сервера. Нулевой пакет не освобождает действительно застрявший трезубец.
- Если опорная collision shape исчезла, клиентский трезубец должен снова падать. До тика проверяется точка позиции с расширением 0.06, как в `AbstractArrow.shouldFall`. Проверяются все затронутые загруженные колонки, включая отрицательные координаты и границы чанков. Ошибка запроса или отсутствующий чанк не считаются воздухом. Существующая форма удерживает трезубец.

Не меняются владелец, Loyalty, предмет/компоненты, урон, подбор и решения сервера о попаданиях. Патч не телепортирует трезубец к игроку и не удаляет чужие сущности. Проверка поддержки вызывается через native_tick и в сетевом клиенте встроенного сервера, и в старом локальном пути.

## Как включить

U3 Fixes теперь устанавливается и включается **автоматически при нажатии «Играть»** в Minecraft Rust, и в офлайн-, и в лицензионном режиме. Отдельную карточку выбирать и подтверждать установку не нужно. Автоматизация разрешена только для точного embedded ZIP U3 Fixes, поставляемого с этой сборкой приложения.

Первая сборка может занять 20-30 минут, требует интернета, инструментов сборки и свободного места. Показываются стадии подготовки и сборки. Повторный запуск использует готовый движок, если контрольные суммы, настройки, включённый патч и build receipt актуальны. После сбоя сборка только собственного патча может быть повторена кнопкой «Играть».

Сохраняются выбранный профиль и его папка игры. Встроенный менеджер сначала собирает патч default-профиля через свой staging-профиль Native mods; после проверки manifests/inputs и хеша движка U3drinth привязывает готовую версию к исходному default-профилю. Миры, настройки и resourcepacks не перемещаются. Перед запуском перечитываются и список профилей, и список версий, чтобы офлайн-команда не запустила старый бинарник.

Сторонний native-код автоматически не получает согласие: добавление U3 Fixes к другим модам разрешено только при действующем ранее подтверждённом build receipt для их полного набора. Если посторонние файлы/настройки изменены или их сборка не завершена, требуется явная проверка и пересборка пользователем. Автоматическая установка не обходит несовместимость версии или проверку целостности.

Карточка U3 Fixes показывает «Автоматически при запуске» или «Установлен», без кнопки ручной установки. Статус относится к выбранному профилю, а не к отдельному профилю U3 Edit.

Manifest намеренно НЕ заявляет совместимость по стабильному hooks API: используются внутренние поля и remote_motion. Разрешена только точная ревизия `3132240f21141518391d7d34d41a4f7b916c3c5a` и mixins `0d6b103c70633d8fd9443d8d0acd3aadaacedb06`. При несовпадении сборка должна быть отклонена, а не применена вслепую. Для встроенного U3 Fixes доверие ограничено точными байтами из приложения; сторонние моды защищены явным согласием на полный набор SHA-256. Проверки установленного набора и build receipt остаются обязательными. Миры не конвертируются.

## Проверки и границы результата

- CPU regression harness извлекает настоящий `ThrownTrident`/`remote_tick` и `back_off` из закреплённых исходников; геометрия, непрозрачное содержимое предмета и мир - небольшие тестовые doubles. Без патча воспроизводятся 2 ожидаемых провала, с патчем проходят 7 тестов: движение, падение после удаления поддержки, нулевая/невалидная скорость, сохранение владельца/Loyalty, существующая поддержка/ошибка запроса, no_physics.
- `horizon-mixins apply` применяет U3 Edit и U3 Fixes одновременно. `cargo check --tests` проверяет патч и тесты с настоящими типами полного Horizon. Это компиляция тестов, не их игровой запуск.
- Тесты лаунчера проверяют детерминированность embedded ZIP и точную привязку ревизии. Для изменения стороннего кода сохраняется требование повторного явного согласия; обновление встроенного U3 Fixes привязано к байтам новой сборки приложения.

**Это не исправление всех багов из ролика.** Огромные предметы, карта, копьё, стрелы с эффектами и другие симптомы всё ещё требуют воспроизведения на конкретной сборке. В закреплённых исходниках обработчики этих механик уже есть; наличие кода не доказывает правильность изображения. Графическая проверка на Windows с игровыми ресурсами здесь не выполнена.

Игровой чек-лист: обычный бросок, попадание в блок/моба, удаление опорного блока, падение рядом с границей чанка, Loyalty 1/3 и Riptide, подбор в survival/creative, локальный мир/сервер, сохранение и повторная загрузка. Сравнивать один мир и одинаковую версию без ресурс-паков, затем с паком.
