# Ресурс-паки Horizon

## Как пользоваться

1. Открой Minecraft Rust. Выбранный профиль задаётся в «Настройки запуска».
2. В «Ресурс-паки Horizon» выбери PvP, Обычные или Modrinth.
3. Нажми «Установить». Лаунчер проверит архив, положит копию в `resourcepacks/` выбранного профиля и включит её. Перезапусти игру.
4. Два пака, которых нет на Modrinth (U3packPvP и Transparent Shield - Mini), появляются в списке после того, как один раз выбрать приложенный `PvP.zip` кнопкой «Добавить архив». Распаковывать и копировать файлы вручную не нужно. Архивы пользователя не публикуются в репозитории.

В списках только паки, которые можно установить. Из 52 исходных паков 33 заявляют диапазон, включающий формат ресурсов 97.1 (Minecraft 26.3): в PvP 7, в Обычных 26. Остальные 19 убраны из каталога: лаунчер не меняет номер формата, чтобы выдавать старые паки за совместимые. Для 31 пака есть точный архив на официальном Modrinth; встроенный каталог дополнительно фиксирует SHA-256.

Modrinth использует настоящий поиск по `project_type:resourcepack` и `versions:26.3`, по 20 записей на страницу. Перед показом страницы лаунчер проверяет каждый пак так же, как при установке, но без скачивания архива: по HTTP-диапазонам читаются только конец ZIP, его оглавление и `pack.mcmeta`. Скрываются паки без файла для 26.3, больше 128 МБ, с форматом не для 97.1, с повреждённым или чужим `pack.mcmeta`, с опасными путями или больше 30000 файлов; на странице видно, сколько скрыто. Если проверить не удалось (нет сети), пак остаётся в списке. Результат запоминается на 30 минут. При установке повторно проверяются тип проекта и версия 26.3, загружается основной файл версии, проверяются размер и SHA-512. Java-моды не устанавливаются в ресурс-паки. Отметка 26.3 не гарантирует поддержку функций OptiFine/CIT/CEM в Horizon.

## Защита интерфейса

По умолчанию включено «Сохранить стандартный интерфейс». Это режим совместимости **для устанавливаемой копии**, не исправление рендера движка. Из копии исключаются GUI, шрифты, GUI-атлас, шейдеры и языковые подмены, в том числе в overlays. Убирается `filter`, который мог бы скрыть штатные ресурсы. Текстуры мира, модели и звуки сохраняются. Исходный архив не перезаписывается.

GUI-пак в таком режиме не изменит меню. Если отключить защиту, устанавливаются оригинальные ресурсы, и проблемы GUI могут вернуться. Лаунчер не обещает полной совместимости произвольного пака.

Если меню уже сломано:

1. Закрой игру.
2. Открой «Установленные ресурс-паки».
3. Нажми «Защитить интерфейс у включённых ZIP-паков».
4. Запусти игру снова.

Будут созданы защищённые копии, оригиналы останутся на диске и будут выключены. Порядок паков и остальные настройки сохраняются. Перед изменением `options.txt` создаётся резервная копия в `u3-pack-backups/` профиля. Можно выключить безопасную копию и включить оригинал из списка. Папки-паки и несовместимые ZIP сначала нужно выключить в игре; операция не будет частично менять список, если один из них не проходит проверку.

Проверяются пути ZIP, дубликаты без учёта регистра, симлинки, CRC, количество файлов и распакованный размер. ZIP не извлекается в каталог игры. Установка недоступна во время игровой сессии/сборки.

## Что проверено

- Unit-тесты проверки форматов, GUI/overlays/filter, ZIP-путей, сохранности файлов, резервных копий и порядка паков.
- Локальная проверка обработки всех 52 исходных архивов без изменения оригиналов.
- Проверка по диапазонам совпала с полной загрузкой и обработкой для 56 популярных паков Modrinth (12 из первых 60 скрыты).
- Импорт настоящего PvP.zip: 14 совпадающих архивов, без записи в игровые каталоги.
- Живой поиск Modrinth и загрузка точного архива с CDN с проверкой хеша.
- UI: поиск, страницы, скрытые паки, защита по умолчанию, ошибки, установка в профиль, узкое окно 390 px.

Не проверен итоговый игровой рендер на Windows. Нельзя считать все визуальные проблемы Horizon исправленными по результатам тестов лаунчера.
