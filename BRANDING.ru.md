# U3drinth — переименование, 0.8.0-3

Название лаунчера изменено на **U3drinth**: метаданные приложения, заголовки Windows и macOS, имя установщика и ярлыков, экран знакомства, информация о версии, сообщения об ошибках и подпись отправляемых логов. Ссылка поддержки лаунчера ведёт в Issues этого форка.

Это независимый форк, а не официальный выпуск Modrinth. Названия реальных сервисов, аккаунтов и формата модпаков Modrinth, домены API и авторские уведомления не переименованы.

## Совместимость при обновлении

Внутренний bundle identifier `ModrinthApp`, каталог `ModrinthApp_Offline`, схема ссылок `modrinth://`, ключ локальных настроек эффектов и имена workspace-пакетов сохранены. Их замена без миграции могла бы разорвать совместимость с профилями, настройками, ссылками и сборкой. Видимое название приложения при этом — U3drinth.

Перед обновлением рекомендуется закрыть лаунчер и сохранить резервную копию профилей. Установка под новым названием может оставить старый ярлык или старую установку; не удаляйте каталог профилей при их очистке. Фактическое обновление установленного приложения нужно отдельно проверить на Windows.

Discord Rich Presence пока использует прежнее зарегистрированное приложение Modrinth. Его имя задаётся в Discord, а не локальной строкой; для полноценного U3drinth Rich Presence нужен собственный Discord Application ID. Интеграцию можно отключить в настройках. Установщик не подписан цифровой подписью.
