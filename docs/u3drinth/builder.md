# U3drinth Builder

`U3drinthBuilder.exe` собирает готовый установщик U3drinth для Windows из исходников так же, как
GitHub Actions (`.github/workflows/windows-installer.yml`): с готовым движком U3 Fixes внутри
(первый запуск игры без компиляции) и лаунчером, собранным с оптимизацией по скорости.

## Как пользоваться

1. Перетащи папку или `.zip` с исходниками на `U3drinthBuilder.exe` (или запусти его и перетащи
   их в окно, затем Enter).
2. Введи версию установщика или нажми Enter, чтобы оставить версию из исходников.
3. Дождись «ГОТОВО». Рядом с исходниками появится `U3drinth<версия>.exe`, например
   `U3drinth1.1.1.exe`, и откроется Проводник.

## Что он делает

- Ставит недостающее, один раз:
  - Visual Studio Build Tools (компилятор C++ и Windows SDK) через установщик Microsoft, нужно
    разрешение администратора; установщик принимается только с действительной подписью Microsoft;
  - в свою папку `%LOCALAPPDATA%\U3drinthBuilder`: Rust (rustup, stable), Node.js 20.20.2,
    pnpm 9.4.0 и Python 3.13.17 (для рецепта движка); загрузки проверяются по SHA-256.
- Копирует исходники в свою рабочую папку (папку с исходниками не трогает) и дальше обновляет там
  только изменившиеся файлы.
- Собирает движок рецептом из самих исходников (`.github/u3-engine/build.py`, штатный
  `native-build` Horizon) и хранит его по ключу: заново собирает только при изменении U3 Fixes или
  Horizon. Если такой же движок уже стоит вместе с установленным U3drinth, берёт его оттуда.
- Выполняет `pnpm install --frozen-lockfile`, затем `tauri build --bundles nsis` с движком и
  выбранной версией. Профиль release тот же, но `opt-level = 3` (скорость) вместо `"s"` (размер).

## Время и место

- Первая сборка: 40–90 минут, на диске около 25 ГБ вместе с Visual Studio.
- Следующие: обычно 5–15 минут, потому что инструменты, движок, зависимости и уже
  скомпилированный код берутся готовыми.

## Параметры

```
U3drinthBuilder.exe [исходники] [--version 1.1.1] [--out ПАПКА] [--tests] [--no-engine] [--yes] [--home ПАПКА]
```

- `--tests` — сначала прогнать тесты интерфейса и лаунчера, как GitHub Actions;
- `--no-engine` — без готового движка (у игроков первый запуск займёт 20–30 минут);
- `--yes` — ничего не спрашивать.

## Если что-то пошло не так

Журнал каждой сборки лежит в `%LOCALAPPDATA%\U3drinthBuilder\logs`. Сборку можно просто запустить
ещё раз: уже готовое второй раз не делается. Чтобы удалить всё, удали папку
`%LOCALAPPDATA%\U3drinthBuilder`; Visual Studio Build Tools удаляются через «Установка и удаление
программ».

Исходники сборщика: `tools/u3-builder`. Его собирает и проверяет `.github/workflows/u3-builder.yml`:
сборка U3drinth из zip дважды (вторая из кэша), установка, запуск лаунчера и установка Visual
Studio Build Tools.
